On incoming mine attacks within the final 10s: if wounded troops exceed infirmary threshold (> threshold%), hospital overflow risks perma-death, so the threatened gatherer must only recall to base and never intercept. If wounded troops are within threshold (<= threshold%), intercept is authorized: the nearest gatherer is recalled if slots are full, intercept squad defends the mine, and squads switch back after impact or 5s after enemy retreat.
